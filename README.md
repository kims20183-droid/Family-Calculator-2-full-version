# Семейный бюджет

Небольшой веб-сайт для планирования семейных финансов: приветственный лендинг и калькулятор доходов и расходов. Работает в браузере без сервера и установки.

## Возможности

- **Главная страница** — краткое описание проекта и переход к калькулятору
- **Калькулятор** — учёт доходов и расходов, остаток, доля расходов, полоса нагрузки, текстовые рекомендации
- **Светлая и тёмная тема** — переключатель в правом нижнем углу, выбор сохраняется в `localStorage`
- **Очистка формы** — кнопка «Очистить» на странице калькулятора

## Структура проекта

```
.
├── index.html          # Лендинг (точка входа)
├── calculator.html     # Калькулятор бюджета
├── css/
│   ├── common.css      # Темы, шапка, общие компоненты
│   ├── landing.css     # Стили главной страницы
│   └── calculator.css  # Стили калькулятора
├── js/
│   ├── theme.js        # Переключение темы
│   └── calculator.js   # Логика расчёта
├── README.md
└── .gitignore
```

Файл `Семейный бюджет.html` оставлен для совместимости: перенаправляет на `index.html`.

## Как запустить

1. Клонируйте или скачайте репозиторий.
2. Откройте **`index.html`** в браузере (двойной клик или «Открыть с помощью»).

Для локального сервера (по желанию):

```bash
# Python 3
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Технологии

HTML5, CSS3 (переменные, адаптивная вёрстка), JavaScript (ES5-совместимый синтаксис).
